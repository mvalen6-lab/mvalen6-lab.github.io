# María Valentina Herrera · Portfolio

Static website, no build tools needed. Publish it free on GitHub Pages at
**https://mvalen6-lab.github.io**

## Publish on GitHub Pages (about 10 minutes)

1. Sign in at github.com as **mvalen6-lab**.
2. Click **+ → New repository**. Name it exactly `mvalen6-lab.github.io`, set it to **Public**, and click **Create repository**.
3. On the new repo page, click **uploading an existing file**.
4. Unzip this folder and drag **everything inside it** (index.html, the `assets` and `projects` folders, README.md) into the upload box. Click **Commit changes**.
5. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
6. Wait 1–2 minutes, then open **https://mvalen6-lab.github.io**.

To change something later, open the file on GitHub, click the pencil icon, edit and **Commit changes**. The site updates in about a minute.

## Optional: your own domain

Buy a domain (for example `mariavalentinaherrera.com`, about $15 CAD/year at Namecheap, Porkbun or Cloudflare).
In the repo go to **Settings → Pages → Custom domain**, type the domain and save, then follow GitHub's DNS
instructions at your registrar. Tick **Enforce HTTPS** once it's available.
